# IA Empresas

Web de herramientas de inteligencia artificial para empresas y PYMEs en España.

## Estructura del proyecto

```
ia-empresas/
├── index.html              # Página principal
├── herramientas-ia/        # Reseñas de herramientas IA
├── comparativas/           # Comparativas directas
├── guias/                  # Guías de implementación
├── casos-uso/              # IA por sector/necesidad
├── noticias/               # Actualidad IA empresarial
├── css/style.css           # Estilos
├── js/main.js              # JavaScript
├── img/                    # Imágenes
├── INFORME-NICHO.md        # Informe completo de consultoría
├── sitemap.xml             # Sitemap XML
├── robots.txt              # Robots.txt
└── ads.txt                 # AdSense
```

## Categorías

- **Herramientas IA**: Reseñas detalladas de software de IA para empresas
- **Comparativas**: Análisis comparativo de herramientas similares
- **Guías**: Guías de implementación y uso práctico
- **Casos de Uso**: IA aplicada por sector o necesidad
- **Noticias**: Actualidad del mundo de la IA empresarial

## Monetización

- Google AdSense (display)
- Afiliados SaaS (comisiones recurrentes)
- Newsletter patrocinada
- Leads para consultores

## Stack técnico

- HTML5 + CSS3 + JS vanilla
- JSON-LD (Schema.org)
- GA4
- Deploy vía SFTP automatizado
