# IA Empresas

Web de herramientas de inteligencia artificial para empresas y PYMEs en España.

## Hospedaje

GitHub Pages (gratuito) → Migración a hosting real cuando toque monetizar con AdSense.

## Estructura

```
ia-empresas/
├── index.html                    # Home
├── herramientas-ia/              # Reseñas
├── comparativas/                 # Comparativas
├── guias/                        # Guías
├── casos-uso/                    # Por sector
├── noticias/                     # Actualidad
├── css/style.css
├── js/main.js
└── img/
```

## Local

```bash
python3 -m http.server 8000
```

## Deploy

Automático vía GitHub Pages al hacer push a `main`.
